# Variations

Read this when the user asks for one of these modes, or when three
generic rounds isn't the right shape for what they brought.

## More or fewer rounds

Three rounds is the default because it's what produces genuine contrast
without repetition setting in — by a fourth or fifth round, invented partners
start rhyming with each other no matter how hard you cast against it. If the
user explicitly wants more, five rounds is a reasonable ceiling; past that,
tell them so and suggest closing instead. If they want fewer, one or two
rounds still works — the exercise degrades gracefully, it just has less to
echo back in the closing.

A single-round version is the fastest legitimate use of this structure: one
partner, one exchange, straight to a closing reflection. Good for a genuinely
quick check-in rather than a full session.

## As a warm-up before a deeper structure

Impromptu Networking's two questions — big challenge, what you hope to
get and give — overlap heavily with the intake questions in Troika Consulting,
Wise Crowds, and Agreement & Certainty. That overlap makes it a natural
warm-up: run Phase 0 through Phase 4 here first, then move straight into the
next structure's intake using the same challenge the user already named,
instead of asking them to restate it from scratch.

Say explicitly when you're making this handoff — "let's take that same
challenge into a Troika round" — so the user knows the two structures are
connected and isn't asked to repeat themselves without explanation. Don't
silently fold Impromptu Networking's closing into the next structure's Phase
0; let the reflection land on its own first, then transition.

This pairs well specifically when the user seems to be circling a challenge
they haven't fully articulated yet — hearing three different people answer
the same two questions is often what sharpens a vague challenge into
something a deeper structure can actually work with.

## Recurring or ritual use

Because it's low-stakes and produces no obligations, this structure tolerates
repeat use better than its siblings — some users will want to run it as a
standing check-in at the start of each new working session, with a fresh set
of three partners each time even when the underlying challenge hasn't
changed. That's a legitimate use. Watch for the challenge itself going stale
across repeats — if the same words come back verbatim in Phase 0 three
sessions running, it may be time to name that directly rather than casting
another round of partners at it.

## Themed casts

When the user names a specific world their challenge lives in — a
conference, a team, a professional community, a hobby group — cast all three
partners from within that world, each a distinctly different kind of person
who'd plausibly be there. A writers' retreat gets a poet, a technical writer,
and someone drafting their first novel, not three generic "creative types."
The specificity of the cast is what makes the closing echoes feel like they
came from a real gathering rather than a generic exercise.

When the challenge is personal, interior, or the domain is genuinely unclear,
optimize for contrast of stance instead of matching a setting — see Casting
in SKILL.md.
