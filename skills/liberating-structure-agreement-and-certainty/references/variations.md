# Variations

Read this when a plain full-list session isn't the right shape for what the
user brought.

## Single-challenge deep version

Skip Phase 0's list entirely — the user has one challenge, not several. Spend
the time you'd have split across many challenges on making the Agreement and
Certainty interrogation in Phase 2 sharper: ask follow-up questions instead
of moving on after the first answer, and push on Phase 4 until the mismatch
(or the confirmed fit) is genuinely specific rather than a one-line
diagnosis. Use when the user opens with "why isn't this one thing working"
rather than "I've got a pile of problems."

## Capture table, for a recurring session

If the user is likely to come back to this — a standing set of
responsibilities, a team they check in on repeatedly — keep a running table
across sessions: challenge, type, current approach, mismatch (or "fit"),
adjustment tried, outcome. Each new session starts by reviewing what changed
since the last placement before diagnosing anything new. This is the source
material's own tip (track outcomes, don't just diagnose once and move on),
adapted to a solo host who has to carry that continuity for the user rather
than a wall chart doing it for a room.

## Pairing forward into Discovery and Action Dialogue

When a mismatch points at a Complex challenge — the fix isn't "do the
obvious thing better," it's "run a safe-to-fail experiment" — don't try to
design that experiment inside this structure's Phase 5. The source material
explicitly suggests pairing forward into another structure for prototyping.
If the challenge is a chronic, shared problem within a group the user can
speak for, and the user suspects some part of that group is already handling
it better than the rest, hand off to
`liberating-structure-discovery-and-action-dialogue` rather than inventing a
generic experiment — DAD surfaces existing positive-deviant practice instead
of importing outside advice, which is usually a better-fitted move for a
Complex mismatch than a fresh recommendation would be.
