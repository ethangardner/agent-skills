# Variations

Read this when the user asks for one of these modes, or when a plain round isn't
the right shape for what they brought.

## Q-storming

Consultants may only ask questions in Phase 3 — never assert, never suggest.
They still speak to each other, third person, so the questions are aimed past
the user rather than at them: "What I want to know is whether he's ever actually
seen the budget, or is just assuming." Twelve to twenty questions, no answers.

Use when the user seems already over-advised, has a strong preexisting view, or
is asking you to validate a decision they've made. It's harder to argue with a
question than with a recommendation.

## 15% Solutions

The client's opening isn't a challenge but a 15% Solution — the piece of the
problem they can move on right now, with their own discretion and resources, no
one's permission required. Everything else runs the same, but Phase 3 is bounded
to that 15%.

Use when the user's challenge is genuinely too big for them to solve alone
(a broken org, a market, another person's behavior) and a full consultation would
produce advice they can't act on. Ask in Phase 0: "What's the part of this you
could move on Monday without anyone's permission?"

## Speed Troika

Compress hard. Phase 1 in one sentence, Phase 2 two questions total, Phase 3 in
250 words. Use when the user has several challenges and wants to triage, or when
they've said they're short on time. Run three of these rather than one full one.

## Fully synthetic mode

No human client. Claude plays all three roles. The user supplies a challenge and
a brief, then reads.

Setup: ask the user for the challenge and for whatever the client would know —
constraints, history, what's already been tried, what the client believes. Then
invent a third persona, the Client, who answers from that brief and stays in
character, including the client's blind spots. If the brief says the client
believes the problem is their manager, the Client persona believes that, and the
consultants get to notice it.

Run all phases with no stops. Length roughly doubles, since the Client's answers
are now content rather than user input.

This is useful for stress-testing a decision from angles the user would rather
not generate themselves — the invented client will defend the position, and
watching the consultants work on a defended position surfaces objections that a
straight critique wouldn't. It loses the part where the enforced silence does
something to the person. Say so if the user seems to be reaching for synthetic
mode as a way to avoid being the one on the receiving end.

## Consultant panels other than two

Two is the structure. But if the user asks for more voices, three consultants
works and produces a genuinely different Phase 3 — with three, coalitions form
and one gets outvoted, which is informative in a way a dyad isn't. Beyond three
the dialogue turns into a queue of monologues. Don't go past four.

## Round-robin over several challenges

If the user brings several challenges, run them as separate rounds rather than
merging them, and keep the same consultants across rounds. Consultants who have
already heard two of someone's problems start making connections between them,
which is one of the better things this structure produces and is impossible in
a single round.
