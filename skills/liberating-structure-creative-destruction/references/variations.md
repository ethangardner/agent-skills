# Variations

Read this when the user brings something narrower than a whole goal, or is
short on time.

## Single-habit Creative Destruction

Instead of a whole goal or project, the user names one specific practice they
suspect is doing damage but haven't been able to pin down — a recurring
meeting, a review process, a way the team communicates, a personal habit like
how they triage email or plan their week.

Run the same six phases, but narrow every one of them to that single habit:

- **Phase 1** — the worst outcome is what this specific habit, left unchecked,
  eventually costs. Not "the project fails" but "we keep having this meeting
  long after it stopped doing anything, and everyone quietly resents the hour."
- **Phase 2** — the Saboteur's brainstorm is scoped tight: everything that
  would make this one habit as damaging as possible. Because the target is
  narrow, the list should still run long — ten to fifteen items is plenty for
  one habit, but push for real range across causes (who calls it, how it's
  scheduled, what it's used to avoid, what it's used to signal).
- **Phase 4** — the audit is usually faster here, because there's only one
  thing to check the list against, but don't let that speed become the same
  premature-consensus failure named in the main skill. A single habit examined
  quickly and shallowly produces "yeah, some of that" instead of "these three
  specific things, confirmed."
- **Phase 5 and 6** — since there's only one habit in scope, "what to stop"
  usually resolves to a binary: keep it in a changed form, or end it outright.
  Push for that clarity rather than a partial list of tweaks.

Use this when the whole-goal version feels too big to be actionable, or when
the user already knows roughly where the problem lives and wants to go deep
rather than wide.

## Quick TRIZ

A compressed pass for when there's genuinely little time, or the user wants a
fast gut-check rather than a full session.

- Phase 1 in one sentence, stated by the host, no back-and-forth.
- Phase 2 capped at eight to ten items from the Saboteur — fast and punchy
  rather than exhaustive.
- Phase 3 still gets its own explicit beat. Do not compress away the tonal
  shift — it's cheap to keep and it's the one thing that can't be cut without
  losing the structure entirely.
- Phase 4 covers the whole list in one pass rather than item-by-item, but
  still requires the user to actually answer, out loud, which ones are real —
  don't let "quick" become "the host guesses."
- Phases 5 and 6 collapse into one move: pick the single worst confirmed item
  and name one first step to stop it. Nothing else.

This trades completeness for speed. It's a good fit for triage across several
goals in one sitting — run it three or four times on different targets rather
than one long pass on one target — or as a warm-up before deciding whether a
full session is worth the time.
