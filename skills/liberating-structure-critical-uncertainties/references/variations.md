# Variations

Read this when the user asks for one of these modes, or when the default run
hits a wall the main phases don't cover.

## The scenario stress-tester (optional persona)

The default session runs with no invented voices — the axis-selection work in
Phase 2 is analytic, not dialogic, and there's nothing for a persona to add
there. But some users want an extra push during Phase 5, when the current
strategy gets tested against each future in turn and it's easy to go soft on
the uncomfortable quadrants.

If the user wants that push, invent one voice: the **stress-tester**. Not a
consultant with a worldview, just a single sharp instrument — for each
quadrant, in character, it asks one question and nothing else: *"If this
future happens, does your plan actually survive?"* Let it sit there
unanswered for a beat before you (as host) answer it honestly on the user's
behalf, working through the mechanism of failure the same way Phase 5 already
asks for.

Keep this genuinely lightweight — one question per quadrant, not a dialogue,
not a personality. The value is the blunt framing, not a character. If it
starts accumulating opinions or a backstory, it's turned into an unwanted
fifth persona and should be cut back down.

## Can't find a second axis

Sometimes every candidate for a second uncertainty keeps failing the checks in
Phase 2 — either it turns out to already be decided, or it turns out to be the
same variable as the first axis restated. If this happens two or three times
and a genuine second axis isn't surfacing, don't force one just to fill out a
2x2. Two options:

**Single-axis version.** Drop the matrix and run a spectrum instead: one
genuinely uncertain factor, laid out as a line with the two poles at either
end. Develop strategies for three or four points along it (both ends plus a
midpoint or two) rather than four quadrants. This is a legitimate simplification
when the honest answer is that the situation really does turn on one thing —
forcing a second, weaker axis into a matrix just to get four boxes produces a
worse result than being honest about having one real uncertainty.

**Widen the search.** Before dropping to a spectrum, try looking in a
different category than the first axis — if the first uncertainty is external
(market, regulatory, competitive), push the brainstorm toward something
internal (organizational capacity, a key relationship, a leadership
transition) or vice versa. Axes drawn from different categories are less
likely to secretly be the same variable than two candidates both pulled from
the same domain. This often surfaces a real second axis that the first pass
missed because it was still circling the same territory.

Use judgment about which to reach for first — if the user is short on time or
the decision is narrow, the single-axis spectrum is often the more honest and
faster path; if the decision is consequential enough to be worth the extra
effort, widen the search before giving up on the matrix.
